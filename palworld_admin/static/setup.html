ボットの作り方

トークンと ID は Discord の画面からコピーしてください。このツールが Discord アカウントを作ることはありません。

  1. Discord Developer Portal で Application を作り、Bot を追加します。Reset Token でトークンをコピーし、下の DISCORD_TOKEN に貼ってください。他人には見せないでください。
  2. Discord のユーザー設定 → 詳細設定 → 開発者モード をオンにします。
  3. 通知したいサーバーの 名前 を右クリック → 「ID をコピー」。これがサーバー ID（guild_id）です。チャンネルの ID ではありません。
  4. 状況を出したいテキストチャンネルを右クリック → 「ID をコピー」（状況チャンネル）。通知を別チャンネルにするなら、通知チャンネルの ID もコピーします。
  5. 自分のユーザー名を右クリック → 「ID をコピー」（/announce 用。空のままでも保存できます）。
  6. 保存すると管理画面の Discord に「ボットをサーバーに招待」が出ます。このツールがトークンから招待 URL を作ります。Developer Portal の OAuth2 → URL Generator で URL を作る必要はありません。リンクには最初から Scopes の bot と applications.commands、権限（チャンネルを見る・メッセージ送信・埋め込み・履歴の閲覧）が入っています。
  7. 自分で URL を作る場合だけ: Portal の OAuth2 → URL Generator で Scopes の bot と applications.commands の両方にチェックし、Bot Permissions で上の 4 つを入れて Generate URL します。applications.commands が無いとスラッシュコマンドが Missing Access になります。
  8. Missing Access なら、サーバーからボットをキックして、同じ招待 URL で入れ直してください。
  9. Discord からゲームサーバーの起動・停止はできません。状況の通知だけです。
