Home Server Admin（無料版）— 使い方
================================

【非公式】
このツールは非公式です。Pocketpair / Palworld とは無関係です。

【同梱していないもの】
・Palworld 専用サーバー（PalServer）
・SteamCMD
・公式のゲームアセット

ゲーム本体は Steam の「Palworld Dedicated Server」を自分の PC に入れてから、
セットアップ画面でそのフォルダを指定してください。

【はじめ方】
1. このフォルダごと好きな場所にコピーします。
2. HomeServerAdmin.exe をダブルクリックします。
3. 初回はセットアップ画面が開きます。PalServer フォルダと AdminPassword を指定し、
   「書き出して起動」を押します。
4. 管理画面からサーバーの起動・停止・設定ができます。

【AdminPassword について】
AdminPassword は REST API 用の管理パスワードです。
友達がゲームに入るときのパスワードではありません。
PalWorldSettings.ini の AdminPassword と同じ値を使います。

【友達の入り方（join_info）】
Discord の /join コマンドに表示する接続方法です。
グローバル IP アドレスとゲームポート（例: 203.0.113.10:8211）を書いてください。
127.0.0.1 は自分の PC からしか使えないため、友達向けには使えません。
空のままにすると Discord では「未設定」と表示されます。

【定時再起動】
管理ツール（HomeServerAdmin.exe）を開いている間だけ、設定した時刻にサーバーを再起動します。
管理ツールを終了すると定時再起動は動きません。

【管理ツールを終了しても】
画面右上の「終了」やウィンドウを閉じても、ゲームサーバー（PalServer）は止まりません。
ゲームを止めたいときは管理画面の「停止」を使ってください。

【Windows SmartScreen】
初回起動時に「Windows によって PC が保護されました」と出ることがあります。
これは署名のない EXE によくある表示です。「詳細情報」→「実行」で起動できます。
